Built around operational reality.

The current repository is a working pilot with explicit boundaries. These pieces are implemented and covered by deterministic tests.

◎

Browser conversation

Microphone and text input over WebSockets, with cancellation of in-flight turns and browser playback.

↗

Inbound phone adapter

Signed Twilio speech webhooks, retry handling, and a configurable human transfer number.

▦

Tenant-scoped records

Persistent calls, events, documents, appointments, and leads with scoped API access.

⌕

Knowledge retrieval

Tenant-isolated text retrieval with source metadata and conservative fallback when facts are unavailable.

✓

Safer booking

Voice bookings require a caller confirmation and a successful calendar operation before confirmation.

◇

Offline evaluation

Deterministic isolation, interruption, webhook, and booking tests plus seeded conversation fixtures.

Traceable from speech to response.
