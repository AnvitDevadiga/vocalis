# Voice pipeline and latency

The browser captures signed 16-bit PCM while the button is held, with a hard 30-second client cap. It sends one WebSocket message for the completed utterance. Capture is monitored through a muted audio node to keep the processor active without feeding microphone audio back to the speakers. Stopping or losing the socket releases the microphone; received audio object URLs are revoked after playback or interruption. Reconnect attempts use bounded exponential backoff.

The server transcribes with faster-whisper locally or Groq Whisper when `VOCALIS_STT_PROVIDER=groq`, retrieves tenant text, calls Groq, persists a reply, then synthesizes MP3 with Edge TTS. The hosted free preview uses Groq Whisper to avoid loading a local speech model into its small instance; audio goes to Groq after the user accepts the updated notice. A new turn cancels the current generation task and instructs the browser to stop playback. A generation counter prevents a stale task from sending audio or committing state after cancellation. This remains whole-utterance speech recognition and full-response synthesis, not token or audio streaming; true acoustic barge-in and voice activity detection are future work.

Measured today: `turn_completed.response_ms` covers retrieval plus LLM and state update. `/api/analytics` calculates p50/p95 only from stored samples, returning `null` with zero samples. `tts_completed.duration_ms` is recorded separately. `speech_end_to_STT_ms`, `STT_to_first_LLM_token_ms`, and `LLM_to_TTS_start_ms` are not available because STT/LLM/TTS are not streamed. Browser network and playback time are not included in `end_to_end_response_ms`; this field is currently server turn processing time and should be renamed when full instrumentation is added.

There is no server-side VAD. Push-to-talk release is the endpoint signal. Interruption is explicit by new turn/button, not acoustic echo cancellation. The phone integration uses Twilio Gather speech turns and Twilio Say, so audio cannot be interrupted by local TTS cancellation. These are deployment blockers for a low-latency real-time claim.
