# Evaluation

`pytest -q` runs deterministic tests without phone/provider credentials. `python -m vocalis.evaluate` runs four seeded fixture conversations and prints their checks and measured local server-turn times. In the current local run, 4/4 fixtures passed; these are fixture checks, not live-provider quality scores. Current checks cover tenant isolation, booking idempotency, voice booking confirmation and slot conflict, cancellation and rebooking, lead deduplication, API-key scoping, Twilio signature calculation, retrieval isolation, escalation, and cancellation of in-flight turns. The suite does **not** constitute a measured task-completion score or full conversation evaluation.

Planned seeded scenarios: booking, cancellation, FAQ, unsupported answer, prompt injection, CRM/calendar failure, human escalation, ambiguous intent, hallucination trap, interruption, and caller changes mind. Each scenario should pin a fixture tenant and provider fake, then compare expected state changes and tool calls. Deterministic metrics should remain separate from any model judge and human review. Collect live traces and sample sizes before publishing latency percentiles, token cost, or hallucination rates.
